# CodeAlpha: Stock Trading Platform

This is a console-based Java application that simulates a stock trading environment. This project was developed as part of my Java Programming Internship at CodeAlpha.

## 🚀 Features
- **Market Data Display:** View available stocks and their current prices.
- **Buy/Sell Operations:** Purchase and sell stocks with real-time balance updates.
- **Portfolio Tracking:** Keep track of owned stocks and total investment value.
- **Object-Oriented Design:** Built using classes like `Stock`, `Portfolio`, and `TradingPlatform`.

## 🛠️ Tech Stack
- **Language:** Java
- **Concepts:** Object-Oriented Programming (OOP), ArrayLists, Scanner Class.

## 📂 Project Structure
- `Stock.java`: Defines the stock object (symbol and price).
- `Portfolio.java`: Manages user balance and owned stocks.
- `StockPlatform.java`: The main engine that handles the user interface and logic.
